# 🚀 Personal Portfolio

A modern, responsive developer portfolio built with React and Tailwind CSS to showcase my skills, projects, education, and journey as a Full Stack Developer.

## 🌐 Live Demo

🔗 https://souravbiswas.in

## ✨ Features

- Modern Dark Theme UI
- Fully Responsive Design
- Smooth Scrolling Navigation
- Skills Showcase
- Project Showcase with Live Demo & GitHub Links
- Education Section
- Resume Download
- Contact Section
- Optimized for Desktop, Tablet, and Mobile

## 🛠️ Tech Stack

### Frontend

- React.js
- Tailwind CSS
- JavaScript (ES6+)
- Vite

### Tools

- Git & GitHub
- VS Code
- Vercel

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/ez-sourav/Portfolio.git
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```
